# Contributing

Thank you for your interest in NanoSleepNet-TCN.

Please keep contributions reproducible and traceable. For model changes, describe the architecture change, dataset/evaluation setting, random seed, and the expected effect on parameters, FLOPs, or predictive performance. For benchmark additions, cite the original publication and clearly state whether the implementation is original, adapted from upstream code, or copied from an upstream repository.

Do not add third-party code without recording its source URL, commit or release identifier, copyright notice, and license. If an upstream project has no explicit license, do not copy its code into this repository without permission; prefer a clean reimplementation from the published method description.

For bug fixes and documentation changes, include enough context for maintainers to reproduce the issue. Avoid committing datasets, credentials, protected health information, or files whose redistribution terms do not permit public hosting.

By submitting a contribution, you confirm that you have the right to contribute the material under the applicable project license and any documented third-party exceptions.
