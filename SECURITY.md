# Security Policy

NanoSleepNet-TCN is research software and is not a medical device.

If you discover a security issue in repository code, deployment assets, or example applications, please report it privately to the maintainers rather than opening a public issue when disclosure could create risk. Contact Guisong Liu at 230258331@seu.edu.cn and include a concise description, affected files or versions, reproduction steps, and any known impact.

Do not include real patient data, credentials, access tokens, private dataset links, or other sensitive information in a public issue.

Clinical performance concerns, dataset-label issues, and model-evaluation questions are generally research-quality issues rather than software-security vulnerabilities, but they should still be reported clearly because this project concerns biomedical signal processing.
